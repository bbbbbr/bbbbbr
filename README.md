#### Tools
- GIMP ROM Bin: plugin to load/save console ROMs as images. [GIMP Plugin](https://github.com/bbbbbr/gimp-rom-bin) (2018)
- GIMP Pixel Art Scalers: [GIMP Plugin](https://github.com/bbbbbr/gimp-plugin-pixel-art-scalers) (2019)
- GIMP Tilemap Helper: plugin for working with game tile maps. [GIMP plugin](https://github.com/bbbbbr/gimp-tilemap-helper) (2019)
- Romusage: Dev tool to report used/available space for Game Boy ROMs. [console](https://github.com/bbbbbr/romusage) (2020)
- GIMP Tilemap GB / png2gbtiles: Import/Export Game Boy GBMB/GBTD graphics. [GIMP plugin](https://github.com/bbbbbr/gimp-tilemap-gb), [console](https://github.com/bbbbbr/gimp-tilemap-gb/tree/master/console) (2020)
- GBToolsID: Identify tools used to build Game Boy ROMs. [web](https://bbbbbr.github.io/gbtoolsid_web/), [console](https://github.com/bbbbbr/gbtoolsid) (2021)
- png2hicolorgb: Build toolchain friendly version of a classic hi-color converter for the GBC. [console](https://github.com/bbbbbr/png2hicolorgb) (2023)
- GIMP Reduce Color Depth: [GIMP Plugin](https://github.com/bbbbbr/gimp-plugin-reduce-color-depth) (2024)
- tilepalquant: C++ console port of rilden's excellent tile based palette quantizer for images. [console](https://github.com/bbbbbr/tilepalquant) (2026)
- png2reducedrgb: Utility for reducing rgb color bit depth. [console](https://github.com/bbbbbr/png2reducedrgb) (2026)
